# 泡泡乐

蓝粉配色的触屏 / 鼠标泡泡生存游戏。静态 HTML、CSS、Canvas 2D 与 WebGL，直接由 GitHub Pages 发布。

## v1.6.1 · 风吹软膜

每颗泡泡根据独立种子生成轮廓偏差、形变轴、软硬程度和运动频率，同色泡泡也各有形态。微小波动沿表面传递，空间风场与移动惯性通过阻尼弹簧驱动形变，形成轻微拖后和回弹。顶点位移及曲面法线在 GPU 与软件降级路径使用相同计算。

## 三维软膜

- 自建索引球体模型：每个泡泡 1,189 个顶点、2,160 个三角形。顶点在 XYZ 空间持续产生细小起伏，表面法线根据实际形变计算。
- 受力位置局部凹陷，其他区域轻微鼓起；阻尼弹簧带来松开后的反向回弹。移动、泡泡接触、边缘碰撞和邻近击破都驱动网格，拖拽时沿手指方向局部拉伸。
- 曲面反射高光、菲涅耳边缘和屏幕空间折射组成透明蓝粉材质。折射读取当帧背景，亮度没有按时间闪烁的动画；这是实时近似材质，并非光线追踪。
- 首页蓝粉模型可按住揉动，凹陷跟随触点，松手后回弹。击破时网格从点击方向开孔消散。
- 首页与游戏共享一个 WebGL 上下文，游戏内每帧批量渲染并合成一次。WebGL 不可用或上下文丢失时，降级为软件绘制的三维三角网格；此时折射效果和性能有限。

## 玩法与手感

- 普通泡泡以**中心所在背景颜色**判定。可以点击，也可以滑过；三维材质的下缘反光增强提示当前同色状态。
- 手指移动达到 8px 才开始滑动判定。扩大的触摸区域只帮助有效命中，触碰空隙会安全略过。
- 受伤后有 550ms 保护，同一次滑动受到伤害时停止继续命中。结算后的输入和得分立即停止。
- 普通泡泡至少获得累计 0.65 秒同色机会，飞出时才计作漏失；路径结束本身不会伪造同色机会。脉冲泡仍按节拍判定。
- 10 / 25 / 50 连击提供反馈和清屏充能，保留原有 100 / 200 连击奖励及排行榜计分结构。
- 首页支持试戳泡泡、自动访客昵称，教程先教成功点击，再介绍生命和特殊泡泡。切换应用后暂停，返回时手动继续。

## 文件

- `game.js`：玩法、输入、UI 与音频。
- `bubble-material.js`：三维网格、顶点形变、透明材质与解析阻尼弹簧，首页和游戏共用。
- `background-engine.js`：背景色场与颜色采样。
- `styles.css`、`ui-polish.css`：基础布局与 Glass 界面。
- `firebase-leaderboard.js`：现有全球排行榜连接。

普通与拖拽泡泡直接绘制三维网格，不使用二维膜贴图或球体动画序列。此前 28 张普通泡泡动画页（约 16.9 MiB）不再启动加载，原始美术资源保留在仓库中。猫咪、炸弹等特殊道具继续使用原有美术。

## 验证与发布

```sh
node --check game.js
node --check bubble-material.js
node --check background-engine.js
node tests/regression.cjs
node tests/mesh.cjs
node tests/webgl.cjs
```

回归测试只依赖 Node.js，覆盖输入中断、误触保护、颜色判定、同色机会、受伤保护、练习重置、键盘暂停和帧率一致性；几何测试验证网格绕序、局部形变、法线精度与体积变化。WebGL 接口测试使用模拟上下文验证批处理和资源生命周期，不替代真实设备上的 GPU 渲染检查。推送到 `main` 时先运行检查，再发布 GitHub Pages。

操作：轻点 / 滑动泡泡；特殊泡泡按教程操作；齿轮或键盘 `P` / `Esc` 暂停，设置内继续游戏。减少动态效果会遵循设备的系统偏好。
