# 泡泡乐

蓝粉配色的触屏 / 鼠标泡泡生存游戏。静态 HTML、CSS 和 Canvas 2D，直接由 GitHub Pages 发布。

## v1.5.0 · Glass

- 自制透明膜材质：透明中心、蓝粉厚边、局部虹彩和高光；普通泡泡保持颜色与亮度连续。
- 阻尼弹簧控制压缩和回弹，面积保持一致，击破会使附近泡泡轻微形变。保留原有运动路径和特殊泡泡。
- 普通泡泡以**中心所在背景颜色**判定。可以点击，也可以滑过；中心标记和下缘亮弧提示当前同色状态。
- 手指移动达到 8px 才开始滑动判定。扩大的触摸区域只帮助有效命中，触碰空隙会安全略过。
- 受伤后有 550ms 保护，同一次滑动受到伤害时停止继续命中。结算后的输入和得分立即停止。
- 普通泡泡至少获得累计 0.65 秒同色机会，飞出时才计作漏失；路径结束本身不会伪造同色机会。脉冲泡仍按节拍判定。
- 10 / 25 / 50 连击提供反馈和清屏充能，保留原有 100 / 200 连击奖励及排行榜计分结构。
- 首页支持试戳泡泡、自动访客昵称，教程先教成功点击，再介绍生命和特殊泡泡。切换应用后暂停，返回时手动继续。

## 文件

- `game.js`：玩法、输入、UI 与音频。
- `bubble-material.js`：缓存膜材质与解析阻尼弹簧，首页和游戏共用。
- `background-engine.js`：背景色场与颜色采样。
- `styles.css`、`ui-polish.css`：基础布局与 Glass 界面。
- `firebase-leaderboard.js`：现有全球排行榜连接。

普通泡泡现在复用两张 256×256 的缓存膜，替代此前启动时请求的 28 张动画页（约 16.9 MiB）。原始美术资源保留在仓库中。

## 验证与发布

```sh
node --check game.js
node --check bubble-material.js
node --check background-engine.js
node tests/regression.cjs
```

回归测试只依赖 Node.js，覆盖输入中断、误触保护、颜色判定、同色机会、受伤保护、练习重置、键盘暂停和帧率一致性。推送到 `main` 时先运行检查，再发布 GitHub Pages。

操作：轻点 / 滑动泡泡；特殊泡泡按教程操作；齿轮或键盘 `P` / `Esc` 暂停，设置内继续游戏。减少动态效果会遵循设备的系统偏好。
